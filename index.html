Kruti Dev ↔ Unicode converter

Convert Hindi text, or whole Word and Excel files, in either direction. Files are processed on this device and never uploaded.

Direction

0 / 50,000

Converts as you type. In this direction every character is treated as Kruti Dev, so leave out English words.

Only text set in a Kruti Dev font is converted. English text in other fonts, tables, layout and page setup are kept as they are.

Proofread names and rare conjuncts (क्ष, त्र, ज्ञ, द्ध) after converting. Old .doc and .xls files must first be saved as .docx or .xlsx.

Kruti Dev output looks like English letters on screen. It shows as Hindi once the Kruti Dev 010 font is applied in Word or Excel.
